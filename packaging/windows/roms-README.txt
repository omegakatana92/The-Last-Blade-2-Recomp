Put your own legally obtained ROM files in this folder.

From lastbld2.zip (MAME set lastbld2):
  243-pg1.p1  243-pg2.sp2
  243-c1.c1   243-c2.c2   243-c3.c3
  243-c4.c4   243-c5.c5   243-c6.c6
  243-s1.s1   243-m1.m1
  243-v1.v1   243-v2.v2   243-v3.v3   243-v4.v4

From neogeo.zip (required BIOS files):
  sp-s2.sp1   sfix.sfix   sm1.sm1   000-lo.lo

The game will not start without these files. No ROMs or BIOS are included in
this distribution. See docs/game-notes.md for the CRC32 and SHA-1 values.
